Quick start

  1. 1
    Install Claude Code
    Install the Claude Code CLI. For Homebrew, WinGet, or npm, see the Claude Code setup guide ↗.
    BASH
    curl -fsSL https://claude.ai/install.sh | bash
  2. 2
    Point it at brewkeg
    Set the base URL and your brewkeg API key — shell exports, or the same vars in ~/.claude/settings.json (%USERPROFILE%\.claude\settings.json on Windows). Open it with code ~/.claude/settings.json — on Windows code "%USERPROFILE%\.claude\settings.json" (CMD) or code "$env:USERPROFILE\.claude\settings.json" (PowerShell). Reuses your existing Anthropic env — no new tool to learn.
    BASH
    export ANTHROPIC_BASE_URL="https://brewkeg.dev" export ANTHROPIC_AUTH_TOKEN="bk_live_YOUR_API_KEY" export ANTHROPIC_DEFAULT_MODEL="brewkeg-ultra" export ANTHROPIC_MODEL="brewkeg-ultra" export ANTHROPIC_DEFAULT_HAIKU_MODEL="brewkeg-nano"
  3. 3
    Launch in your project
    Start Claude Code from your project root. Every model id in the picker now routes through brewkeg.
    BASH
    claude --model brewkeg-ultra
  4. 4
    Verify
    Ask anything. Check /dashboard/requests — a new row appears within seconds.
