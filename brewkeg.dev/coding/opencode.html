Quick start

  1. 1
    Install OpenCode
    Install the agent, then open it once so the config folders exist.
    BASH
    curl -fsSL https://opencode.ai/v2/install | bash
  2. 2
    Declare the brewkeg provider
    Save this as ~/.config/opencode/opencode.json (%USERPROFILE%\.config\opencode\opencode.json on Windows) — model keys must match the ids brewkeg serves exactly.
    JSON
    { "$schema": "https://opencode.ai/config.json", "model": "brewkeg/brewkeg-ultra", "providers": { "brewkeg": { "name": "Brewkeg", "package": "@opencode/ai/providers/openai-compatible", "settings": { "baseURL": "https://brewkeg.dev/v1", "apiKey": "{env:BREWKEG_API_KEY}" }, "models": { "brewkeg-ultra": { "name": "brewkeg-ultra" } } } } }
  3. 3
    Export your key
    The config reads the key from $BREWKEG_API_KEY, so it never sits in the file. Put this in your shell profile, then open a new terminal.
    BASH
    export BREWKEG_API_KEY="bk_live_YOUR_API_KEY"
  4. 4
    Verify
    Run a smoke prompt — a new row appears in /dashboard/requests within seconds.
    BASH
    opencode run "Reply with: PONG"
