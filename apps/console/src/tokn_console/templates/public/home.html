Common questions.

Does Tokn change my agent's config?

No. You set a base URL and a key in the client you already use.

Which agents does it work with?

Claude Code, Codex CLI, OpenCode, Cline, Roo, Continue and Cursor. Features that bypass a custom endpoint are listed in each guide.

Where does my key go?

In the authorisation header of each request. Never in a URL, a log line or a page.

Which models can I use?

Whatever the catalogue enables for your account, at the prices on the receipt.

How much does it cost?

Per token, at the price on the receipt. No subscription, no monthly minimum.

What if my balance runs out mid-request?

It cannot. The worst case is held first, so a request either fits or is refused with a 402.

What if a request fails upstream?

You are not charged. The hold is released in full.

Do you train on my prompts?

No. They are not stored.
