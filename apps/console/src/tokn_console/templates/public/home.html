What we store, and what we do not.

We store

Your account, your keys as hashes, your wallet and ledger, and one receipt per request: model, tokens, cost, latency, outcome.

We never store

Prompts, completions, request bodies or authorisation headers. There is no toggle, because there is nothing to toggle.

Your key stays with you.

A key carries its own limits, and you can end it at any moment without touching anything else.

Shown once, stored hashed

The secret exists in the moment you create it. After that the database holds an HMAC digest, so a dump is not a set of keys.

Capped per key

A spend cap and an expiry. When either is reached the key stops; it does not overspend and it does not ask twice.

Revoked immediately

Revocation clears the cache entry first, so the next request fails. Not within a minute — on the next request.

Questions, answered.

Does Tokn change my agent's config?

No. You set a base URL and a key in the client you already use. Nothing is rewritten and nothing is replaced.

Which agents does it work with?

Any client that supports a custom OpenAI or Anthropic base URL: Claude Code, Codex CLI, OpenCode, Cline, Roo, Continue and Cursor. Some product features bypass a custom endpoint entirely; the docs say which.

Where does my key go?

To the gateway you are calling, in the authorisation header of each request. It is never placed in a URL, a log line or a page.

Which models can I use?

Whatever the catalogue enables for your account. The console lists the real model names with their input, output and cache prices.

How much does it cost?

Per token, at the price on the receipt. There is no subscription and no monthly minimum; credit never expires.

What happens if my balance runs out mid-request?

It cannot. The worst case is held before the request starts, so it either fits or is refused with a 402 before anything runs.

What if a request fails upstream?

You are not charged. The hold is returned in full and the attempt is recorded with an upstream error outcome.

Do you train on my prompts?

No. They are not stored, so there is nothing to train on.

Priced per token, not per month.

Every model carries its own input, output and cache price, and the price that applied is written on the receipt. Top up any amount; it does not lapse.

The catalogue is not published yet

Prices are read from the live catalogue rather than written into this page. Once models are enabled, their real per-million prices appear here and in the console.
