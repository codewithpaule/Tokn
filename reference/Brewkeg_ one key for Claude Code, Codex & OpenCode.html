Your key stays with you.

brewkeg is a local binary. It edits your dotfiles, keeps a copy of everything it replaces, and hands your key straight to the agent you already use.

Backed up before every write

brewkeg copies each file into ~/.brewkeg/backups/<id>/ before it changes a single byte. A backup is created even when the change turns out to be nothing.

Scoped to your account

One key, your account, your requests. There is no shared pool and no relay — brewkeg is not in the path between your agent and the model.

Nothing left behind

brewkeg reset disconnects every target and forgets the key. Your API keys, usage history and backups stay exactly where they were.
